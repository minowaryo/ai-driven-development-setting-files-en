# UAT Results (Optional, Non-Blocking)

A place to record the results of acceptance testing performed against `docs/product/uat-scenarios.md`.

## Operating Rules

- Final confirmation is done by a human (reviewer / business side)
- Recommended file naming: `{UC-number}-uat-result.md` (e.g. `uc001-uat-result.md`)
- The status of UAT execution/approval is never a reason to halt development of other features or the TDD cycle (see `.claude/rules/00-global.md`)
